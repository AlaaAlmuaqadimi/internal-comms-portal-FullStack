# مجلد الأيقونات والصور

ضع هنا جميع الأيقونات والصور المطلوبة للتطبيق:

- `icon.png` - أيقونة التطبيق (1024x1024)
- `splash.png` - شاشة البداية (1284x2778)
- `adaptive-icon.png` - أيقونة متكيفة لأندرويد (1024x1024)
- `favicon.png` - أيقونة الويب (48x48)

## ملاحظة

يمكنك استخدام نفس الأيقونات الموجودة في المشروع الأصلي أو إنشاء أيقونات جديدة متوافقة مع الهوية البصرية.
